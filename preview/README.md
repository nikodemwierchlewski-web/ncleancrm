# Aktualny podgląd: ruchomy ncLEANEK

[Jeden plik HTML](ncleanek-floating.html) lub [ZIP](ncleanek-floating-demo.zip). Wypakuj ZIP i otwórz index.html albo pobierz pojedynczy HTML i otwórz w aktualnej przeglądarce wykonującej JavaScript.

Kliknij/tapnij ludzika, aby od razu zobaczyć podpowiedzi bieżącego ekranu. Przeciąganie wyłącznie lewo/prawo uruchamia pozę podnoszenia za rękę. Domyślnie prawy dolny róg, bez skoków i zmiany rozmiaru. W Opcjach są przypomnienia, reset i zmiana strony. Strzałki lewo/prawo przesuwają, Home resetuje, Enter otwiera pomoc. Rozmiar jest stały: 44×60 px. Postać zostaje na dolnej krawędzi, a w kolizji z zapisem lub aktywnym polem przepuszcza dotyk. Przypomnienie Dokończ dzień prowadzi do brakujących danych; można je odłożyć na 20 minut lub wyciszyć w Opcjach.

To syntetyczna demonstracja 62 widoków istniejącej aplikacji, z zapisem symulowanym w pamięci. Odświeżenie resetuje sesję; paczka nie łączy się z bazą. Nie wpisuj rzeczywistych danych klientów. Widok pliku w menedżerze telefonu może nie uruchamiać JavaScript — nie jest równoważny przeglądarce. Nie uruchomiono publicznego hostingu.

[Wyniki testów i instrukcja](../docs/NCLEANEK-BOTTOM-RAIL-RESULTS.md). [Commit i sumy kontrolne](build.json). Starsze paczki pozostają archiwalne.
